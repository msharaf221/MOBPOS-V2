## ☁️ منظومة Supabase السحابية والاقتران السريع (Supabase Cloud Sync & Instant QR Pairing)

تم تركيز المنظومة السحابية بنسبة 100% على **Supabase** كحل سحابي فائق السرعة والأمان، مع إلغاء كافة متطلبات وتعقيدات Google Cloud Console وGoogle Drive API وOAuth:

* **بدون إعدادات خارجية معقدة (Zero-Friction Cloud):** لا حاجة لإنشاء حسابات مطورين أو شاشات موافقة OAuth أو ضبط Client IDs معقدة؛ التطبيق مهيأ ومربوط مسبقاً بسحابة Supabase الفائقة.
* **عزل المتاجر والفروع السحابي (Tenant Isolation):** يتم عزل بيانات كل متجر وفرع بدقة فائقة عبر `tenant_id` داخل سحابة Supabase، مما يضمن أمان وخصوصية البيانات التامة بين المتاجر.
* **اقتران الهاتف بمسح رمز الـ QR خلال ثانيتين فقط:**
  - توليد كود QR مشفر بلمسة زر من شاشة إعدادات الكمبيوتر.
  - مسح الكود فورياً عبر كاميرا الهاتف من تطبيق الموبايل لربط الفرع فوراً ومزامنة المنتجات والخزن والأسعار والمبيعات في أجزاء من الثانية.
* **نسخ احتياطي سحابي شامل (One-Click Cloud Snapshot):** حفظ لقطات كاملة لكافة جداول النظام ومخازن البيانات داخل سحابة Supabase بلمسة زر واحدة مع حفظ النسخ المحلية الدورية.

## 📱 تطبيق الموبايل المصاحب (MOBPOS Companion App)

تطبيق محمول متكامل مبني باستخدام **Capacitor 8** و **React 19**، يمنح صاحب المحل والمدير تحكماً كاملاً من أي مكان مع فصل مالي دقيق:

* **تصميم فاخر بنمط Fintech:** واجهة مستخدم داكنة بزجاجية بلورية (Glassmorphism)، وبطاقات Bento تفاعلية، وشريط تنقل عائم (Floating Dock).
* **الربط التام لفواتير المبيعات بين الديسكتوب والموبايل:**
  - توافق بنيوي 100% في مخطط الفاتورة: إجمالي الخصم، المدفوع، المتبقي، طريقة السداد، اسم ورقم العميل، وتفاصيل البنود مع التكلفة (`inventoryId`, `costPrice`).
  - ظهور فواتير الموبايل في شاشة مبيعات الديسكتوب مع إمكانية البحث باسم العميل أو رقمه أو أرقام IMEI وأسماء المنتجات، واستعراض تفاصيل الفاتورة كاملة.
* **الفصل المالي والمحاسبي الدقيق (Accurate Profit Accounting):**
  - 🟢 **مجمل ربح المبيعات والصيانة:** احتساب مجمل الربح كحاصل طرح تكلفة البضاعة المباعة (COGS) من الإيرادات الصافية؛ مع منع اعتبار الأصناف غير المسجل تكلفتها ربحاً بنسبة 100% لتفادي التضليل المحاسبي.
  - 🔴 **خصم المصروفات التشغيلية:** طرح المصروفات اليومية والمسحوبات تلقائياً للوصول إلى **صافي الربح التشغيلي الحقيقي** (Net Operating Profit).
  - 🔵 **ركن إيرادات وورشة الصيانة:** إجمالي متحصلات الصيانة لليوم، صافي ربح الصيانة، عدد الأجهزة المسلمة اليوم، والأجهزة الجارية قيد الإصلاح.
  - 🟡 **ركن الأصول والسيولة المالية:** السيولة النقدية الكاش المتوفرة فعلياً في خزن الفرع (معزولة تماماً عن الأرباح النظرية)، وتقييم المخزون ورأس المال المحبوس في الرفوف.
* **كاميرا قراءة الباركود وIMEI السريعة المرتبطة بـ Supabase:**
  - معالجة وإصلاح مشاكل شاشات الكاميرا السوداء في المتصفح والـ WebView عبر ضبط تشغيل الفيديو الصامت `autoPlay playsInline muted`.
  - محرك مسح مزدوج ذكي: محرك `BarcodeDetector` النيتف فائق السرعة مع بديل `ZXing Canvas Frame Reader` الذي يمنع تعليق أو تأخر إشارات الفيديو نهائياً.
  - **بحث سحابي مباشر في Supabase:** عند مسح أي باركود أو سيريال IMEI (15 رقماً) غير موجود بالذاكرة المؤقتة، يستعلم الهاتف فوراً من جداول `mobpos_records` (لمخزن `inventory` ومخزن `imei_units`) ولقطة `mobpos_stores`، ويجلب المنتج ببياناته وسعره وتكلفته ويضيفه لسلة المبيعات أو شاشة الجرد فوراً!
* **زر فحص وتثبيت التحديثات في تطبيق الموبايل (In-App Mobile Updater):**
  - زر مخصص «فحص التحديثات 🔄» في تبويب الإعدادات يتصل مباشرة بـ GitHub Releases API.
  - مقارنة ذكية للإصدارات وفق قواعد Semantic Versioning وعرض نافذة منبثقة بتفاصيل الإصدار الجديد وتاريخه وسجل التغييرات مع زر تنزيل وتثبيت الـ APK مباشرة.
* **إدارة ورشة الصيانة وتسليم الأجهزة من الهاتف:**
  - استلام تذاكر الصيانة وتسجيل بيانات العطل وقطع الغيار والتكلفة المتوقعة.
  - تسليم الجهاز للعميل نقدياً مع تحديد المبلغ المحصل وتكلفة القطع، واحتساب ربح الصيانة اللحظي، وتوريد النقدية لأي خزينة مختارة مع تحديث رصيدها سحابياً فوراً (Read-Modify-Write).
  - إرسال رسائل واتساب للعميل بضغطة زر واحدة لإبلاغه بحالة جهازه وجاهزيته للاستلام.
* **إدارة الفروع المتعددة (Multi-Branch Manager):**
  - حفظ ومزامنة فروع متعددة مع التبديل الفوري بنقرة واحدة بين الفروع.
  - مؤشر ذكي لحالة اتصال الفرع ونبض المزامنة الحي.
* **جرد الخزن والتحويلات:** تسجيل وتأكيد المصروفات والإيداعات وتحويلات المحافظ الإلكترونية مباشرة من الهاتف.

## ☁️ محرك المزامنة السحابية (Cloud Auto Sync v2.1)

نظام مزامنة سحابي لحظي فائق الاستقرار، مصمم وفق مبادئ **Offline-First** الحقيقية:

* **استقرار بصري تام ومنع الرعشة (Anti-Fluttering State Machine):**
  - معالجة ذكية لحالات الاتصال تمنع وميض وتذبذب بادج المزامنة في شريط العنوان نهائياً.
  - تدرج زمني أسي ذكي لإعادة المحاولة (Exponential Backoff من 5 إلى 60 ثانية) مع سقف أمان يحمي الشبكة من استنزاف الموارد.
* **دورة مزامنة شاملة بنقرة واحدة (`syncNow`):**
  - تفريغ طابور العمليات المعلقة في الأوفلاين (`syncOutbox`) ورفعها فوراً.
  - جلب التعديلات الجديدة الصادرة من الأجهزة الأخرى (`pullCatchUp`).
  - رفع لقطة شاملة للمخازن المالية والمخزون (`pushAllSnapshots`) بترتيب أولويات يحمي استقرار البيانات.
* **التعافي التلقائي وحصانة التخزين (Self-Healing Storage):**
  - حفظ بيانات الاتصال والسيرفر في طبقتين متزامنتين (IndexedDB + localStorage) لضمان عدم فقدان الإعدادات إطلاقاً.
  - كشف تلقائي للجلسات المنتهية والتحويل الفوري لمفتاح Anon Key دون تعطيل الكاشير.
* **مخطط قاعدة بيانات عالمي متوافق (Universal Idempotent Schema v2.1):**
  - متوافق 100% مع أي مشروع Supabase جديد أو قائم.
  - سياسات وصول مفتوحة للصلاحيات (Permissive RLS) تمنع أخطاء الصلاحيات في الاستخدام اليومي.
  - كرت نسخ مباشر لكود SQL من داخل شاشة الإعدادات ونافذة المزامنة بلمسة واحدة.

## 📡 نظام الشبكة المحلية (Local LAN Hub)

إذا كان المحل يعاني من ضعف أو انقطاع الإنترنت، يمتلك MOBPOS **خادم شبكة داخلية مدمج (Local LAN Server)**:

* **ربط هواتف الكاشير والتابلت بجهاز الكمبيوتر الرئيسي:** مشاركة نفس شبكة الواي فاي بدون الحاجة لاتصال خارجي بالإنترنت.
* **اكتشاف تلقائي للعناوين:** يكتشف النظام عناوين IP المحلية تلقائياً ويعرض رابطاً سريعاً يمكن فتحه من أي هاتف.
* **مصادقة آمنة عبر PIN:** تسجيل دخول سريع للموظفين والكاشير عبر رمز PIN المخصص للمتجر.

## ✨ المميزات الرئيسية للنظام

### 🛒 نقطة بيع احترافية وسريعة (Ultra-Fast POS)
- **مسح باركود فوري:** دعم كافة أجهزة قراءة الباركود السلكية واللاسلكية وكاميرات الموبايل.
- **توليد باركود EAN-13 معتمد:** كود مصري ببادئة `622` مع حساب خانة التحقق (Check Digit) وطباعة ملصقات الرفوف.
- **ربط سيريال IMEI بالبيع:** اختيار السيريال من القائمة مع ربطه تلقائياً بالفاتورة والعميل والضمان.
- **تعليق الفواتير (Park/Hold):** حفظ سلة مؤقتاً لخدمة عميل آخر والعودة لها فوراً.
- **طرق دفع متعددة:** كاش، فيزا/بطاقة، محافظ إلكترونية، أو آجل على حساب العميل.
- **طباعة حرارية صامتة:** طباعة إيصالات 80mm مباشرة للطابعة الافتراضية بدون نوافذ متصفح مزعجة.

### 📱 إدارة أرقام IMEI والضمان
- تتبع كامل لكل جهاز برقمه التسلسلي الفريد (`IMEI1` + `IMEI2`).
- تسجيل اللون، السعة، الحالة (جديد / كسر زيرو / مستعمل)، وسعر التكلفة وسعر البيع.
- **متابعة الضمان:** عداد ذكي يوضح الأيام المتبقية وتنبيه بالأجهزة التي شارف ضمانها على الانتهاء.
- سجل تاريخي لكل جهاز: مين استورده، مين باعه، تاريخ الخروج، وهل خضع للصيانة.

### 🔧 إدارة قسم الصيانة وقطع الغيار (مزامنة تامة ديسكتوب وموبايل)
- **تذكرة صيانة برقم تلقائي:** تسجيل بيانات العميل، نوع الجهاز، العطل، وكلمة سر قفل الشاشة.
- **لوحة كانبان (Kanban Board):** استعراض التذاكر (مستلم ⬅️ تحت الفحص ⬅️ تم الإصلاح ⬅️ تم التسليم).
- **خصم قطع الغيار من المخزون تلقائياً:** حساب تكلفة الشاشة أو البطارية ومصنعية الفني وأرباح الصيانة بدقة.
- **تسليم فوري وتحصيل من الموبايل أو الديسكتوب:** تسجيل المبلغ المحصل الفعلي، واحتساب صافي ربح التذكرة وتوريد النقدية لأي خزينة مختارة مع تحديث رصيدها سحابياً ومحلياً.
- **تواصل فوري عبر WhatsApp:** إرسال إشعار للعميل بحالة الجهاز والمبلغ المطلوب بلمسة واحدة.
- طباعة إيصال استلام احترافي للعميل مع الشروط والأحكام.

### 💰 الخزائن المتعددة والمعاملات المالية
- خزائن منفصلة: الخزنة النقدية بالمحل، محافظ فودافون كاش / اتصالات كاش، والحسابات البنكية.
- تسجيل تحويلات الخزن مع تسجيل عمولات عمليات السحب والإيداع وحساب الأرباح الناتجة عنها.
- شجرة حسابات جانبية (Side Accounts) للديون والمستحقات الخارجية والشركاء.

### 👥 العملاء، الموردين، والمرتجعات
- كشف حساب تفصيلي لكل عميل ولكل مورد مع تتبع الأرصدة والمدفوعات الآجلة.
- معالجة المرتجعات الآمنة: استرجاع البضاعة للمخزن وتعديل الخزينة أو رصيد العميل أوتوماتيكياً.
- فواتير توريد ومشتريات بالكميات أو بأرقام IMEI دفعة واحدة.

### 📊 التقارير والإغلاق اليومي (Daily Closing Reports)
- **تقرير تقفيل اليومية الشامل:** صافي حركة الكاش الفعلي، أرباح مبيعات البضاعة، إيرادات وأرباح الصيانة، المصروفات، المشتريات، الديون المحصلة، والمرتجعات.
- **تعريب تلقائي لكافة الحركات المالية:** تصنيف وعرض الحركات بالعربية الفصحى لسهولة المراجعة والتدقيق.
- **تصدير كامل إلى Excel (XLSX):** جداول منسقة بدعم RTL وأرقام قابلة للمعادلات والمجاميع.
- **تصدير وحفظ تقارير PDF رسمية:** خط Cairo عربي مضمن داخل التقارير ومتاح للطباعة والأرشفة مباشرة.

## 🛡️ الأمان والاعتمادية

| الميزة | التفاصيل الفنية |
|---|---|
| **تشفير كلمات المرور** | معيار `PBKDF2-HMAC-SHA-256` مع ملح عشوائي (Salt) فريد لكل مستخدم |
| **مفاتيح التراخيص الرقمية** | توقيع تشفيري غير متماثل عبر خوارزمية `ECDSA P-256` وبصمة الجهاز |
| **قاعدة البيانات المحلية** | `IndexedDB v8` سريعة جداً بدون أي حد أقصى للبيانات سوى مساحة القرص |
| **حماية الشبكة في Electron** | سياسة أمان محتوى صارمة (CSP) محدثة تمنع تسريب البيانات وتحمي الاتصالات |
| **نسخ احتياطي متعدد** | نسخ احتياطي محلي يومي (IndexedDB/JSON) + لقطات سحابية شاملة فورية في Supabase |

## 🧪 الجودة والاختبارات التلقائية (139 Tests + E2E)

يخضع نظام **MOBPOS-V2** لفحص شامل ومستمر عبر حزمة اختبارات برمجية تغطي كافة السيناريوهات الحسابية والتشغيلية:

```bash
# تشغيل اختبارات الوحدة (139 اختباراً)
npm test

# تشغيل اختبار دورة المبيعات الشاملة المتكاملة (E2E POS Sales Cycle)
npm run test:e2e

# تشغيل الفحص الكامل مع فحص الأنواع
npm run test:all

# التحقق من قناة التحديث التلقائي بنفس طريقة تطبيق العميل
npm run verify:updates
```

* ✅ **139 اختبار وحدة ناجح بنسبة 100%:** يشمل محرك تسلسل الفواتير، الإغلاق اليومي وحسابات الصيانة والديون، محاسبة الأرباح الصافية والمجملة، تشفير كلمات المرور PBKDF2، فحص الـ JWT، توليد الباركود الدولي EAN-13، وأمان ومزامنة الخزن والشبكة المحلية، ومقارنة إصدارات الموبايل السحابية.
* ✅ **اختبار Playwright E2E:** محاكاة حقيقية لعملية بيع كاملة في نقطة البيع (مسح الصنف ⬅️ تطبيق خصم ⬅️ اختيار الخزنة ⬅️ إنهاء الفاتورة ⬅️ طباعة الإيصال ⬅️ خصم المخزن ⬅️ عمل مرتجع واستعادة الكمية).
* ✅ **أداة الفحص المستمر لقنوات التحديث (`verify:updates`):** فحص حي لقناة التحديثات الأوتوماتيكية للتأكد من وصول التحديثات فورياً لكافة العملاء دون أخطاء.

## 🛠️ متطلبات التثبيت والتشغيل للمطورين

### المتطلبات
- **Node.js 20+** (LTS)
- **npm** (أو yarn / pnpm)

### التشغيل المحلي
```bash
# 1. استنساخ المستودع
git clone https://github.com/msharaf221/MOBPOS-V2.git
cd MOBPOS-V2

# 2. تثبيت الاعتماديات
npm install

# 3. تشغيل خادم التطوير (Web)
npm run dev

# 4. تشغيل نسخة سطح المكتب (Electron Dev)
npm run electron:dev
```

### أوامر بناء حزم الإنتاج
```bash
# بناء حزمة الويب المضغوطة
npm run build

# بناء تطبيق ويندوز المثبت (Installer EXE)
npm run dist:win

# بناء تطبيق ويندوز المحمول (Portable EXE)
npm run dist:win:portable

# بناء تطبيق الموبايل (Android & iOS Web Assets)
npm run mobile:build
```
