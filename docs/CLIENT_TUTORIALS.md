# 📱 دليل فيديوهات شرح وتشغيل نظام MOBPOS للعملاء الجدد

مجموعة متكاملة من فيديوهات الشرح العملية بجودة عالية (720p HD) وصيغة MP4 خفيفة وسريعة (أقل من 1.5 ميجابايت لكل فيديو)، مناسبة تماماً للإرسال عبر **الواتساب (WhatsApp)**، التليجرام، أو عرضها داخل البرنامج والموقع مباشرة.

كل فيديو يحتوي على مؤشر أحمر تفاعلي يتتبع حركة الماوس والنقرات، مع شريط إرشادي باللغة العربية أسفل الشاشة يوضح للعميل ما يتم فعله في كل خطوة.

## 💬 نصوص ورسائل جاهزة للنسخ والإرسال للعملاء على الواتساب

### 1️⃣ شرح عملية البيع وإصدار الفاتورة:
```text
أهلاً بحضرتك يا فندم! 📱
ده فيديو سريع (دقيقة واحدة) بيشرح لحضرتك ازاي تعمل أول فاتورة بيع على نظام MOBPOS:
- اختيار أو مسح باركود المنتج.
- تطبيق خصم على الفاتورة.
- إتمام الدفع (كاش أو محفظة).
- طباعة فاتورة الكاشير الحرارية مقاس 80mm بضغطة زر.
لو عندك أي استفسار فريق الدعم معاك خطوة بخطوة! ✨
```

---

### 2️⃣ شرح إضافة الأصناف وتوليد الباركود:
```text
أهلاً بحضرتك! 📦
الفيديو ده بيوضح لحضرتك ازاي تضيف صنف جديد في المخزن:
- تسجيل اسم المنتج والماركة والتصنيف.
- توليد باركود أوتوماتيك بضغطة واحدة لو المنتج ملوش باركود.
- تحديد سعر التكلفة وسعر البيع وحد الطلب للتنبيه قبل النفاذ.
- حفظ وتحديث الكميات فورياً.
```

---

### 3️⃣ شرح تسجيل ومتابعة أجهزة IMEI وفترة الضمان:
```text
أهلاً بك يا فندم! 🔍
شرح سريع لطريقة إدارة أجهزة السيريال و IMEI:
- تسجيل الجهاز برقم الـ IMEI (15 رقم) ولونه وسعته.
- تحديد حالة الجهاز (جديد أو مستعمل) وفترة الضمان.
- البحث الفوري بأي رقم IMEI لمعرفة حالة الجهاز وتاريخ بيعه في ثانية واحدة!
```

---

### 4️⃣ شرح استلام جهاز صيانة وتتبع التذكرة:
```text
أهلاً بحضرتك! 🛠️
الفيديو ده بيشرح دورة الصيانة الكاملة في محلك:
- تسجيل بيانات العميل ونوع الجهاز والمشكلة والتكلفة المبدئية.
- طباعة إيصال استلام رسمي للعميل برقم التذكرة والباركود.
- تحديث حالة الجهاز على لوحة الكانبان (قيد الاستلام ⬅️ تحت الإصلاح ⬅️ مكتمل).
```

---

### 5️⃣ شرح حركة الخزائن وتقفيل الوردية والإقفال اليومي:
```text
أهلاً بحضرتك! 💰
طريقة إدارة الخزائن والتقفيل اليومي في MOBPOS:
- متابعة رصيد الخزنة الرئيسية، درج الكاشير، وفودافون كاش.
- تحويل مبالغ نقدية بين الخزائن بضغطة زر.
- استخراج تقرير الإقفال اليومي الشامل لمطابقة المبيعات والمصروفات والدرج وطباعته أو حفظه PDF.
```

## 🛠️ أوامر إعادة التسجيل أو التحديث لاحقاً

جميع الفيديوهات مؤتمتة بنسبة 100% باستخدام Playwright و ffmpeg. يمكنك إعادة توليد أي فيديو أو تعديله في أي وقت من خلال الأوامر التالية:

```bash
# لتسجيل جميع الفيديوهات الخمسة دفعة واحدة:
npm run tutorials:record

# أو تسجيل فيديو محدد:
npm run tutorials:pos          # تسجيل فيديو نقطة البيع
npm run tutorials:inventory    # تسجيل فيديو المخزون
npm run tutorials:imei         # تسجيل فيديو IMEI
npm run tutorials:maintenance  # تسجيل فيديو الصيانة
npm run tutorials:safes        # تسجيل فيديو الخزائن والإقفال اليومي
```

> **ملاحظة فنية:** الفيديوهات موجودة في مجلد `public/tutorials/`، مما يعني أنه عند تشغيل الموقع أو السيرفر، تكون متاحة مباشرة عبر الرابط `https://your-domain/tutorials/01-pos-sale-tutorial.mp4` بدون الحاجة لأي إعدادات إضافية.
