# Mobile phase — MOBPOS-V2 (2026-10)

Branch: `refactor/full-audit-restructure`

## Scope

1. **Desktop web on phone (LAN)** — open main POS UI in mobile browser on the same network  
2. **Companion app** (`mobile/`) — Capacitor multi-branch monitor via Supabase  

## Changes

### A. Main app (LAN browser)

| Change | Detail |
|--------|--------|
| Responsive sidebar | ≤767px: overlay drawer from the right (RTL), closed by default |
| Scrim + close | Tap outside closes drawer; navigate closes on mobile |
| Header menu | Hamburger in main header on small screens |
| Viewport | `viewport-fit=cover` for notched devices |

### B. Companion (`mobile/`)

| Change | Detail |
|--------|--------|
| Fetch timeout | 18s per branch via `withTimeout` |
| Aggregate resilience | `Promise.allSettled` — one slow/dead branch does not block others |
| Short metrics cache | 30s TTL before re-hitting Supabase when switching tabs |
| Safe areas / PWA meta | Already present (`safe-bottom`, `viewport-fit=cover`, manifest) |

## Operator notes

- **LAN POS on phone:** open `http://<PC-LAN-IP>:<port>` after login; session token required for data/sync (security phase).  
- **Companion:** configure each branch’s Supabase URL + anon key + optional `tenantId` in Settings tab.  
- Build APK: existing workflows `build-mobile-apk.yml` / `build-mobile-ios.yml`.
