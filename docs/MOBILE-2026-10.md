# Mobile Phase — MOBPOS-V2 (2026-10)

## Overview

MOBPOS-V2 provides a dual mobile ecosystem:
1. **Desktop Web on Phone (LAN)** — Open the full desktop POS UI in any browser on the same Wi-Fi network with session security.
2. **Native/PWA Companion Mobile POS (`mobile/`)** — High-performance multi-branch executive monitor and full mobile cashier powered by Supabase Realtime.

---

## Architecture & Features

### A. Main App (LAN Browser)

| Feature | Detail |
|---------|--------|
| **Responsive Sidebar** | Responsive drawer overlay (RTL), touch-friendly scrim, auto-close on navigate |
| **Header Menu** | Hamburger menu toggle on mobile viewports |
| **Viewport & Touch** | `viewport-fit=cover` for notched displays and safe area insets |

### B. Companion Mobile POS (`mobile/`)

| Feature | Detail |
|---------|--------|
| **Bi-directional Cloud Push** | Real-time atomic upserts to `mobpos_records` broadcasting via Supabase Realtime to PC and phones |
| **Mobile POS Terminal (`POSTab`)** | Live catalog search, category pills, cart drawer, IMEI selector, customer selection, multiple payment methods (Cash, Instapay, Card, Debt) |
| **Native Camera Barcode Scanner** | Modern high-fps `BarcodeDetector` API with torch toggle, laser reticle, and manual barcode/IMEI fallback |
| **Quick Action Modal** | Instant expense logging, cash deposits to safes, and fast inventory product addition from the phone |
| **Active Maintenance Hub** | Receive new repair tickets, advance workflow stages, and collect payment directly into safe upon delivery |
| **Debt Collection Hub** | Instant customer debt collection into safe + 1-tap WhatsApp debt reminder messages |
| **Native Audio & Haptics** | Web Audio API sound synthesis (zero external files): barcode beep, cash register chime, success sound, and haptic feedback |
| **Elevated Center Navigation** | Glowing elevated quick-POS button in bottom nav + instant header settings access |
| **Resilience & Caching** | 18s per-branch timeout, `Promise.allSettled`, 30s TTL metrics cache, live Supabase WebSocket alerts |

---

## Operator Guide

- **LAN POS on phone:** Open `http://<PC-LAN-IP>:<port>` after logging in; session token required for data/sync.
- **Companion Mobile POS:** Configure each branch’s Supabase URL + anon key + optional `tenantId` in the Settings tab.
  - All sales, expenses, and maintenance delivered on phone instantly broadcast to PC cashiers and all mobile companions.
- **Build & Packaging:**
  - Web/PWA build: `npm run mobile:build`
  - Android APK: `cd mobile && npx cap sync android` or GitHub Actions `build-mobile-apk.yml`.
